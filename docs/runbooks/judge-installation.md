Confluence is optional, and is needed for PRD and page workflows. You need site administrator permission to install the app and approve its declared scopes.

The judge app is a separate identity from the paid Marketplace app. It uses the same application capabilities and source code. Local example mode is not used for the live submission screenshots or video.

1. Open **Apps → Promisory → Connections**, select one Jira project and save. Enable Confluence if you want page and PRD workflows.
2. Create a commitment with an outcome, beneficiary, nominated owner, deadline and acceptance conditions. The owner must accept accountability before the commitment becomes active. Link a permitted epic, task, story or bug using the real configured Jira hierarchy.
3. Inspect the overview, work map and inbox. Ask the Promisory Rovo agent to explain a commitment or turn a permitted PRD into cited candidate commitments. The agent drafts; it cannot approve or execute.
4. To use the external read-only MCP tools, a site administrator enables the Promisory tools under Connected apps. The user then approves the MCP client's Read and Search consent. Graph context remains inside Atlassian and is excluded from the MCP response.
5. On a judge's own installation, governed execution remains unavailable until a matching institutional authority binding is provisioned. A review does not bypass that boundary.

For a successful governed-write walkthrough, use the dedicated test site access arranged privately with the submitter. A separate reviewer account is required. Credentials are never published here. The selected test guest account still requires recipient activation before access can be used.
