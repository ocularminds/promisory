It did not establish the exact module value or verify OAuth. The fixed failure vocabulary previously grouped all other module values together. This update follows the documented hosted-compute gap and requires a signed native runtime attestation on every connection/action/reconciliation request. [Architecture and sources](../../decisions/0012-bind-hosted-forge-invocations.md).

The attestation is taken from Forge's trusted `getAppContext()` and signed with the exact method, route and body. It is not a UI/model field. Missing or conflicting runtime context, unrecognized modules, old signatures and request changes are rejected. A blank FIT module is explicitly reported as absent; it is not silently substituted with a fabricated Atlassian claim. All site/user/OAuth, policy/review/grant and recovery requirements remain in force.
