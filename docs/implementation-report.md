## Authority and residual concurrency

The only external mutation implemented is Jira's `duedate` field. Promisory's remote calls `SafeExecutor` from `@decionis/agent-safe-pipeline@0.5.0`; no action-gate Boolean or dossier can dispatch the write. Shadow, unconfigured or unverified enforcement remains held. The browser and Rovo cannot supply effective tenant identity, policy mode, arbitrary API URLs or an approval role. Rovo proposals remain Atlassian-only and require a separately authored user intent before any remote action.

A single-aggregate SQL compare-and-set protects each local operation. A durable remote journal prevents a second dispatch for that operation. An uncertain send moves to reconciliation; reconciliation has no write capability. OAuth tokens exist only in the current invocation. Encrypted claim material supports recovery across a remote restart. A finalization replay rejection is retained as pending evidence, not interpreted as a recorded receipt.

Jira's selected update path has no verified atomic source-version condition. A native edit can race the last precheck and PUT. Narrow set-field semantics and read-back expose conflicts, but do not provide a global lock or exactly-once effects across native Jira activity. Multiple remote replicas require a shared atomic journal before deployment; the included durable file store is for one host and one bound installation.
