The app uses no individual productivity ranking, inferred management hierarchy, external analytics connector or general customer-message sender. Code does not log raw API bodies, OAuth headers or secret values. Infrastructure access logs must also redact authorization, user-token and signature headers before the remote is deployed.

## Retention and deletion status

The product proposal suggests 24-hour source caches and 180-day operational history. This implementation uses per-invocation source memoization, so it has no persistent shared source-body cache. Configuration records contain a 180-day history value, but **automatic history expiry, export and deletion jobs are not implemented**. Do not promise a 180-day deletion guarantee from that field.

Disconnect disables configured app access/actions and retains app records. It never deletes Jira issues or Confluence pages. Reinstallation uses a distinct installation scope. Forge uninstall/recovery periods and remote/provider erasure must be verified against the actual deployment and service contracts. Uninstalling Forge does not establish that external journal, sealed claim or Decionis evidence has been erased.

Before launch, decide and implement authorized export, irreversible erasure handling, retry/pending-claim retention, backup expiry, provider retention, deletion verification and a real support request route. Keep pending claims available for safe reconciliation until the approved lifecycle process addresses them; indiscriminate cleanup must not turn uncertainty into a new dispatch.

## Consent and subprocessors

The remote is optional. Basic manually entered commitments and source exploration can operate while external actions remain unavailable. Enabling the remote requires explicit sharing of the independently authored due-date intent and the narrow REST snapshot on both Forge and remote sides. Required scopes and the declared external storage domain must be disclosed in installation/review materials.

Atlassian hosts Forge/Rovo and the native source products. The owner-selected remote host and Decionis authority provider/region are not yet configured for Promisory. No data residency, certification, legal compliance, uptime, support SLA or “Runs on Atlassian” claim is made by this candidate.
